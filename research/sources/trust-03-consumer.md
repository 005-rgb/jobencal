|  |  | b. | bahwa pembangunan perekonomian nasional pada era <br>globalisasi harus dapat mendukung tumbuhnya dunia usaha sehingga mampu <br>menghasilkan beraneka barang dan/atau jasa yang memiliki kandungan teknologi <br>yang dapat meningkatkan kesejahteraan masyarakat banyak dan sekaligus <br>mendapatkan kepastian atas barang dan/atau jasa yang diperoleh dari <br>perdagangan tanpa mengakibatkan kerugian konsumen; |
|  |  | c. | bahwa semakin terbukanya pasar nasional sebagai <br>akibat dari proses globalisasi ekonomi harus tetap menjamin peningkatan <br>kesejahteraan masyarakat serta kepastian atas mutu, jumlah, dan keamanan <br>barang dan/atau jasa yang diperolehnya di pasar; |

|  |  | e. | bahwa ketetentuan hukum yang melindungi <br>kepentingan konsumen di Indonesia belum memadai; |
|  |  | f. | bahwa berdasarkan pertimbangan tersebut di atas <br>diperlukan perangkat peraturan perundang-undangan untuk mewujudkan <br>keseimbangan perlindungan kepentingan konsumen dan pelaku usaha sehingga <br>tercipta perekonomian yang sehat; |
|  |  | g. | bahwau untuk itu perlu dibentuk Undang-undang <br>tentang Perlindungan Konsumen; |

|  | BAB I<br>KETENTUAN UMUM<br>Pasal 1 |
|  |  | Dalam Undang-undang ini yang dimaksud dengan : |
|  |  | 1. | Perlindungan konsumen adalah segala upaya yang <br>menjamin adanya kepastian hukum untuk memberi perlindungan kepada konsumen. |
|  |  | 2. | Konsumen adalah setiap orang pemakai barang dan/atau <br>jasa yang tersedia dalam masyarakat, baik bagi kepentingan diri sendiri, <br>keluarga, orang lain, maupun makhluk hidup lain dan tidak untuk <br>diperdagangkan. |
|  |  | 3. | Pelaku usaha adalah setiap orang perseorangan atau <br>badan usaha, baik yang berbentuk badan hukum maupun bukan badan hukum yang <br>didirikan dan berkedudukan atau melakukan kegiatan dalam wilayah hukum <br>negara Republik Indonesia, baik sendiri maupun bersama-sama melalui <br>perjanjian menyelenggarakan kegiatan usaha dalam berbagai bidang ekonomi. |
|  |  | 4. | Barang adalah setiap benda baik berwujud maupun <br>tidak berwujud, baik bergerak maupun tidak bergerak, dapat dihabiskan maupun <br>tidak dapat dihabiskan, yang dapat untuk diperdagangkan, dipakai, <br>dipergunakan, atau dimanfaatkan oleh konsumen. |
|  |  | 5. | Jasa adalah setiap layanan yang berbentuk <br>pekerjaan atau prestasi yang disediakan bagi masyarakat untuk dimanfaatkan <br>oleh konsumen. |
|  |  | 6. | Promosi adalah kegiatan pengenalan atau <br>penyebarluasan informasi suatu barang dan/atau jasa untuk menarik minat beli <br>konsumen terhadap barang dan/atau jasa yang akan dan sedang diperdagangkan. |
|  |  | 7. | Impor barang adalah kegiatan memasukkan barang ke <br>dalam daerah pabean. |
|  |  | 8. | Impor jasa adalah kegiatan penyediaan jasa asing <br>untuk digunakan di dalam wilayah Republik Indonesia. |
|  |  | 9. | Lembaga Perlindungan Konsumen Swadaya Masyarakat <br>adalah lembaga non-Pemerintah yang terdaftar dan diakui oleh Pemerintah yang <br>mempunyai kegiatan menangani perlindungan konsumen. |
|  |  | 10. | Klausula Baku adalah setiap aturan atau ketentuan <br>dan syarat-syarat yang telah dipersiapkan dan ditetapkan terlebih dahulu <br>secara sepihak oleh pelaku usaha yang dituangkan dalam suatu dokumen dan/atau <br>perjanjian yang mengikat dan wajib dipenuhi oleh konsumen. |
|  |  | 11. | Badan Penyelesaian Sengketa Konsumen adalah badan <br>yang bertugas menangani dan menyelesaikan sengketa antara pelaku usaha dan <br>konsumen. |
|  |  | 12. | Badan Perlindungan Konsumen Nasional adalah badan <br>yang dibentuk untuk membantu upaya pengembangan perlindungan konsumen. |
|  |  | 13. | Menteri adalah menteri yang ruang lingkup tugas <br>dan tanggung jawabnya meliputi bidang perdagangan. |
|  | BAB II<br>ASAS DAN TUJUAN<br>Pasal 2 |
|  |  | Perlindungan konsumen berasaskan manfaat, keadilan, <br>keseimbangan, keamanan dan keselamatan konsumen, serta kepastian hukum. |
|  | Pasal 3 |
|  |  | Perlindungan konsumen bertujuan : |
|  |  | a. | meningkatkan kesadaran, kemampuan dan kemandirian <br>konsumen untuk melindungi diri; |
|  |  | b. | mengangkat harkat dan martabat konsumen dengan <br>cara menghindarkannya dari ekses negatif pemakaian barang dan/atau jasa; |
|  |  | c. | meningkatkan pemberdayaan konsumen dalam memilih, <br>menentukan, dan menuntut hak-haknya sebagai konsumen; |
|  |  | d. | menciptakan sistem perlindungan konsumen yang <br>mengandung unsur kepastian hukum dan keterbukaan informasi serta akses untuk <br>mendapatkan informasi; |
|  |  | e. | menumbuhkan kesadaran pelaku usaha mengenai <br>pentingnya perlindungan konsumen sehingga tumbuh sikap yang jujur dan <br>bertanggung jawab dalam berusaha; |
|  |  | f. | meningkatkan kualitas barang dan/atau jasa yang <br>menjamin kelangsungan usaha produksi barang dan/atau jasa, kesehatan, <br>kenyamanan, keamanan, dan keselamatan konsumen. |
|  | BAB III<br>HAK DAN KEWAJIBAN<br>Bagian Pertama<br>Hak dan Kewajiban Konsumen<br>Pasal 4 |
|  |  | Hak konsumen adalah : |
|  |  | a. | hak atas kenyamanan, keamanan, dan keselamatan <br>dalam mengkonsumsi barang dan/atau jasa; |
|  |  | b. | hak untuk memilih barang dan/atau jasa serta <br>mendapatkan barang dan/atau jasa tersebut sesuai dengan nilai tukar dan <br>kondisi serta jaminan yang dijanjikan; |
|  |  | c. | hak atas informasi yang benar, jelas, dan jujur <br>mengenai kondisi dan jaminan barang dan/atau jasa; |
|  |  | d. | hak untuk didengar pendapat dan keluhannya atas <br>barang dan/atau jasa yang digunakan; |
|  |  | e. | hak untuk mendapatkan advokasi, perlindungan, dan <br>upaya penyelesaian sengketa perlindungan konsumen secara patut; |
|  |  | f. | hak untuk mendapat pembinaan dan pendidikan <br>konsumen; |
|  |  | g. | hak untuk diperlakukan atau dilayani secara benar <br>dan jujur serta tidak diskriminatif; |
|  |  | h. | hak untuk mendapatkan kompensasi, ganti rugi dan/atau <br>penggantian, apabila barang dan/atau jasa yang diterima tidak sesuai dengan <br>perjanjian atau tidak sebagaimana mestinya; |
|  |  | i. | hak-hak yang diatur dalam ketentuan peraturan <br>perundang-undangan lainnya. |
|  | Pasal 5 |
|  |  | Kewajiban konsumen adalah : |
|  |  | a. | membaca atau mengikuti petunjuk informasi dan <br>prosedur pemakaian atau pemanfaatan barang dan/atau jasa demi keamanan dan <br>keselamatan; |
|  |  | b. | beritikad baik dalam melakukan transaksi pembelian <br>barang dan/atau jasa; |
|  |  | c. | membayar sesuai dengan nilai tukar yang disepakati; |
|  |  | d. | mengikuti upaya penyelesaian hukum sengketa <br>perlindungan konsumen secara patut. |
|  | Bagian <br>Kedua<br>Hak dan Kewajiban Pelaku Usaha<br>Pasal 6 |
|  |  | Hak pelaku usaha adalah : |
|  |  | a. | hak untuk menerima pembayaran yang sesuai dengan <br>kesepakatan mengenai kondisi dan nilai tukar barang dan/atau jasa yang <br>diperdagangkan; |
|  |  | b. | hak untuk mendapat perlindungan hukum dari <br>tindakan konsumen yang beritikad tidak baik; |
|  |  | c. | hak untuk melakukan pembelaan diri sepatutnya di <br>dalam penyelesaian hukum sengketa konsumen; |
|  |  | d. | hak untuk rehabilitasi nama baik apabila terbukti <br>secara hukum bahwa kerugian konsumen tidak diakibatkan oleh barang dan/atau <br>jasa yang diperdagangkan; |
|  |  | e. | hak-hak yang diatur dalam ketentuan peraturan <br>perundang-undangan lainnya. |
|  | Pasal 7 |
|  |  | Kewajiban pelaku usaha adalah : |
|  |  | a. | beritikad baik dalam melakukan kegiatan usahanya; |
|  |  | b. | memberikan informasi yang benar, jelas dan jujur <br>mengenai kondisi dan jaminan barang dan/atau jasa serta memberi penjelasan <br>penggunaan, perbaikan dan pemeliharaan; |
|  |  | c. | memperlakukan atau melayani konsumen secara benar <br>dan jujur serta tidak diskriminatif; |
|  |  | d. | menjamin mutu barang dan/atau jasa yang diproduksi <br>dan/atau diperdagangkan berdasarkan ketentuan standar mutu barang dan/atau <br>jasa yang berlaku; |
|  |  | e. | memberi kesempatan kepada konsumen untuk menguji, <br>dan/atau mencoba barang dan/atau jasa tertentu serta memberi jaminan dan/atau <br>garansi atas barang yang dibuat dan/atau yang diperdagangkan; |
|  |  | f. | memberi kompensasi, ganti rugi dan/atau <br>penggantian atas kerugian akibat penggunaan, pemakaian dan pemanfaatan <br>barang dan/atau jasa yang diperdagangkan; |
|  |  | g | memberi kompensasi, ganti rugi dan/atau <br>penggantian apabila barang dan/atau jasa yang diterima atau dimanfaatkan <br>tidak sesuai dengan perjanjian. |
|  | BAB IV<br>PERBUATAN YANG DILARANG<br>BAGI PELAKU USAHA<br>Pasal 8 |
|  |  | (1) | Pelaku usaha dilarang memproduksi dan/atau <br>memperdagangkan barang dan/atau jasa yang : |
|  |  |  | a. | tidak memenuhi atau tidak sesuai dengan standar <br>yang dipersyaratkan dan ketentuan peraturan perundang-undangan; |
|  |  |  | b. | tidak sesuai dengan berat bersih, isi bersih atau <br>netto, dan jumlah dalam hitungan sebagaimana yang dinyatakan dalam label <br>atau etiket barang tersebut; |
|  |  |  | c. | tidak sesuai dengan ukuran, takaran, timbangan dan <br>jumlah dalam hitungan menurut ukuran yang sebenarnya; |
|  |  |  | d. | tidak sesuai dengan kondisi, jaminan, keistimewaan <br>atau kemanjuran sebagaimana dinyatakan dalam label, etiket atau keterangan <br>barang dan/atau jasa tersebut; |
|  |  |  | e. | tidak sesuai dengan mutu, tingkatan, komposisi, <br>proses pengolahan, gaya, mode, atau penggunaan tertentu sebagaimana <br>dinyatakan dalam label atau keterangan barang dan/atau jasa tersebut; |
|  |  |  | f. | tidak sesuai dengan janji yang dinyatakan dalam <br>label, etiket, keterangan, iklan atau promosi penjualan barang dan/atau jasa <br>tersebut; |
|  |  |  | g. | tidak mencantumkan tanggal kadaluwarsa atau jangka <br>waktu pengunaan/pemanfaatan yang paling baik atas barang tertentu; |
|  |  |  | h. | tidak mengikuti ketentuan berproduksi secara halal, <br>sebagaimana pernyataan "halal" yang dicantumkan dalam label; |
|  |  |  | i. | tidak memasang label atau membuat penjelasan <br>barang yang memuat nama barang, ukuran, berat/isi bersih atau netto, <br>komposisi, aturan pakai, tanggal pembuatan, akibat sampingan, nama dan <br>alamat pelaku usaha serta keterangan lain untuk penggunaan yang menurut <br>ketentuan harus dipasang/dibuat; |
|  |  |  | j. | tidak mencantumkan informasi dan/atau petunjuk <br>penggunaan barang dalam bahasa Indonesia sesuai dengan ketentuan <br>perundang-undangan yang berlaku. |
|  |  | (2) | Pelaku usaha dilarang memperdagangkan barang yang <br>rusak, cacat atau bekas, dan tercemar tanpa memberikan informasi secara <br>lengkap dan benar atas barang dimaksud. |
|  |  | (3) | Pelaku usaha dilarang memperdagangkan sediaan <br>farmasi dan pangan yang rusak, cacat atau bekas dan tercemar, dengan atau <br>tanpa memberikan informasi secara lengkap dan benar. |
|  |  | (4) | Pelaku usaha yang melakukan pelanggaran pada ayat <br>(1) dan ayat (2) dilarang memperdagangkan barang dan/atau jasa tersebut <br>serta wajib menariknya dari peredaran. |
|  | Pasal 9 |
|  |  | (1) | Pelaku usaha dilarang menawarkan, memproduksikan, <br>mengiklankan suatu barang dan/atau jasa secara tidak benar, dan/atau <br>seolah-olah : |
|  |  |  | a. | barang tersebut telah memenuhi dan/atau memiliki <br>potongan harga, harga khusus, standar mutu tertentu, gaya atau mode tertentu, <br>karakteristik tertentu, sejarah atau guna tertentu; |
|  |  |  | b. | barang tersebut dalam keadaan baik dan/atau baru; |
|  |  |  | c. | barang dan/atau jasa tersebut telah mendapatkan <br>dan/atau memiliki sponsor, persetujuan, perlengkapan tertentu, keuntungan <br>tertentu, ciri-ciri kerja atau aksesori tertentu; |
|  |  |  | d. | barang dan/atau jasa tersebut dibuat oleh <br>perusahaan yang mempunyai sponsor, persetujuan atau afiliasi; |
|  |  |  | e. | barang dan/atau jasa tersebut tersedia; |
|  |  |  | f. | barang tersebut tidak mengandung cacat tersembunyi; |
|  |  |  | g. | barang tersebut merupakan kelengkapan dari barang <br>tertentu; |
|  |  |  | h. | barang tersebut berasal dari daerah tertentu: |
|  |  |  | i. | secara langsung atau tidak langsung merendahkan <br>barang dan/atau jasa lain; |
|  |  |  | j. | menggunakan kata-kata yang berlebihan, seperti <br>aman, tidak berbahaya, tidak mengandung risiko atau efek sampingan tanpa <br>keterangan yang lengkap; |
|  |  |  | k. | menawarkan sesuatu yang mengandung janji yang <br>belum pasti. |
|  |  | (2) | Barang dan/atau jasa sebagaimana dimaksud pada <br>ayat (1) dilarang untuk diperdagangkan. |
|  |  | (3) | Pelaku usaha yang melakukan pelanggaran terhadap <br>ayat (1) dilarang melanjutkan penawaran, promosi, dan pengiklanan barang dan/atau <br>jasa tersebut. |
|  | Pasal 10 |
|  |  | Pelaku usaha dalam menawarkan barang dan/atau jasa <br>yang ditujukan untuk diperdagangkan dilarang menawarkan, mempromosikan, <br>mengiklankan atau membuat pernyataan yang tidak benar atau menyesatkan <br>mengenai : |
|  |  | a. | harga atau tarif suatu barang dan/atau jasa; |
|  |  | b. | kegunaan suatu barang dan/atau jasa; |
|  |  | c. | kondisi, tanggungan, jaminan, hak atau ganti rugi <br>atas suatu barang dan/atau jasa; |
|  |  | d. | tawaran potongan harga atau hadiah menarik yang <br>ditawarkan; |
|  |  | e. | bahaya penggunaan barang dan/atau jasa. |
|  | Pasal 11 |
|  |  | Pelaku usaha dalam hal penjualan yang dilakukan <br>melalui cara obral atau lelang, dilarang mengelabui/menyesatkan konsumen <br>dengan : |
|  |  | a. | menyatakan barang dan/atau jasa tersebut <br>seolah-olah telah memenuhi standar mutu tertentu; |
|  |  | b. | menyatakan barang dan/atau jasa tersebut <br>seolah-olah tidak mengandung cacat tersembunyi; |
|  |  | c. | tidak berniat untuk menjual barang yang ditawarkan <br>melainkan dengan maksud untuk menjual barang lain; |
|  |  | d. | tidak menyediakan barang dalam jumlah tertentu dan/atau <br>jumlah yang cukup dengan maksud menjual barang yang lain; |
|  |  | e. | tidak menyediakan jasa dalam kapasitas tertentu <br>atau dalam jumlah cukup dengan maksud menjual jasa yang lain; |
|  |  | f. | menaikkan harga atau tarif barang dan/atau jasa <br>sebelum melakukan obral. |
|  | Pasal 12 |
|  |  | Pelaku usaha dilarang menawarkan, mempromosikan <br>atau mengiklankan suatu barang dan/atau jasa dengan harga atau tarif khusus <br>dalam waktu dan jumlah tertentu, jika pelaku usaha tersebut tidak bermaksud <br>untuk melaksanakannya sesuai dengan waktu dan jumlah yang ditawarkan, <br>dipromosikan, atau diiklankan. |
|  | Pasal 13 |
|  |  | (1) | Pelaku usaha dilarang menawarkan, mempromosikan, <br>atau mengiklankan suatu barang dan/atau jasa dengan cara menjanjikan <br>pemberian hadiah berupa barang dan/atau jasa lain secara cuma-cuma dengan <br>maksud tidak memberikannya atau memberikan tidak sebagaimana yang <br>dijanjikannya. |
|  |  | (2) | Pelaku usaha dilarang menawarkan, nempromosikan <br>atau mengiklankan obat, obat tradisional, suplemen makanan, alat kesehatan, <br>dan jasa pelayanan kesehatan dengan cara menjanjikan pemberian hadiah berupa <br>barang dan/atau jasa lain. |
|  | Pasal 14 |
|  |  | Pelaku usaha dalam menawarkan barang dan/atau jasa <br>yang ditujukan untuk diperdagangkan dengan memberikan hadiah melalui cara <br>undian, dilarang untuk : |
|  |  | a. | tidak melakukan penarikan hadiah setelah batas <br>waktu yang dijanjikan; |
|  |  | b. | mengumumkan hasilnya tidak melalui media massa; |
|  |  | c. | memberikan hadiah tidak sesuai dengan yang <br>dijanjikan; |
|  |  | d. | mengganti hadiah yang tidak setara dengan nilai <br>hadiah yang dijanjikan. |
|  | Pasal 15 |
|  |  | Pelaku usaha dalam menawarkaan barang dan/atau <br>jasa dilarang melakukan dengan cara pemaksaan atau cara lain yang dapat <br>menimbulkan gangguan baik fisik maupun psikis terhadap konsumen. |
|  | Pasal 16 |
|  |  | Pelaku usaha dalam menawarkan barang dan/atau jasa <br>melalui pesanan dilarang untuk : |
|  |  | a. | tidak menepati pesanan dan/atau kesepakatan waktu <br>penyelesaian sesuai dengan yang dijanjikan; |
|  |  | b. | tidak menepati janji atas suatu pelayanan dan/atau <br>prestasi. |
|  | Pasal 17 |
|  |  | (1) | Pelaku usaha periklanan dilarang memproduksi iklan <br>yang : |
|  |  |  | a. | mengelabui konsumen mengenai kualitas, kuantitas, <br>bahan, kegunaan dan harga barang dan/atau tarif jasa serta ketepatan waktu <br>penerimaan barang dan/atau jasa; |
|  |  |  | b. | mengelabui jaminan/garansi terhadap barang dan/atau <br>jasa; |
|  |  |  | c. | memuat informasi yang keliru, salah, atau tidak <br>tepat mengenai barang dan/atau jasa; |
|  |  |  | d. | tidak memuat informasi mengenai risiko pemakaian <br>barang dan/atau jasa; |
|  |  |  | e. | mengeksploitasi kejadian dan/atau seseorang tanpa <br>seizin yang berwenang atau persetujuan yang bersangkutan; |
|  |  |  | f. | melanggar etika dan/atau ketentuan peraturan <br>perundang-undangan mengenai periklanan. |
|  |  | (2) | Pelaku usaha periklanan dilarang melanjutkan <br>peredaran iklan yang telah melanggar ketentuan pada ayat (1). |
|  | BAB V<br>KETENTUAN PENCANTUMAN KLAUSULA BAKU<br>Pasal <br>18 |
|  |  | (1) | Pelaku usaha dalam menawarkan barang dan/atau jasa <br>yang ditujukan untuk diperdagangkan dilarang membuat atau mencantumkan <br>klausula baku pada setiap dokumen dan/atau perjanjian apabila : |
|  |  |  | a. | menyatakan pengalihan tanggung jawab pelaku usaha; |
|  |  |  | b. | menyatakan bahwa pelaku usaha berhak menolak <br>penyerahan kembali barang yang dibeli konsumen; |
|  |  |  | c. | menyatakan bahwa pelaku usaha berhak menolak <br>penyerahan kembali uang yang dibayarkan atas barang dan/atau jasa yang <br>dibeli oleh konsumen; |
|  |  |  | d. | menyatakan pemberian kuasa dari konsumen kepada <br>pelaku usaha baik secara langsung maupun tidak langsung untuk melakukan <br>segala tindakan sepihak yang berkaitan dengan barang yang dibeli oleh <br>konsumen secara angsuran; |
|  |  |  | e. | mengatur perihal pembuktian atas hilangnya <br>kegunaan barang atau pemanfaatan jasa yang dibeli oleh konsumen; |

|  |  | (5) | Putusan <br>badan penyelesaian sengketa konsumen sebagaimana dimaksud pada ayat (3) <br>merupakan bukti permulaan yang cukup bagi penyidik untuk melakukan <br>penyidikan. |
